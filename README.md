# Кохання — це ти

Статичний сайт-альбом без збірки: `index.html`, `styles.css`, `app.js`, `assets/`.

## Локально
```
python3 -m http.server 5173
```
Відкрити http://localhost:5173. Додайте `?reset` до адреси, щоб знову побачити екран з паролем.

## Деплой
Залийте всю папку (крім `tools/` і `README.md`) на будь-який статичний хостинг з HTTPS: Netlify Drop, Vercel, GitHub Pages, Cloudflare Pages.

## Що де міняти
- Тексти, порядок сторінок, відео розділів: блок `content` на початку `app.js`.
- Пароль: `SECRET` в `app.js`. Це лише грайливий замок, а не захист: хто знає адреси файлів, відкриє їх і без пароля.
- Ассети перезбираються з вихідників: `python3 tools/build_assets.py "<docx>" "<папка з mp4>"`.
